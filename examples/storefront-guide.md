# 网店购物问答：独立交互演示

[返回作品集](../README.md) · [客服系统项目经历](../cases/ai-customer-support.md)

这是为作品集从零编写的独立代码示例：虚构桌面用品商店“桌间”，展示商品陈列、购物问答、条款溯源与联系人工流程。商品、价格和政策均为自建演示内容。

[在线体验购物问答](https://super-chestnut.github.io/portfolio/examples/customer-assistant.html)：使用虚构商品与政策、本地知识检索，未接入语言模型。

## 本地打开

下载本目录后，用现代浏览器直接打开 [customer-assistant.html](customer-assistant.html)。无需安装依赖、运行服务器或配置账号；HTML 内含全部 CSS、JavaScript 与 SVG 插图，离线可用。

GitHub 的文件浏览页显示源码；可以通过在线入口体验，也可以下载到本地打开。

## 可以实际操作

- 打开、关闭购物问答面板；点击商品卡把对应问题带入对话。
- 输入问题并按 Enter 发送，或选择快捷问法。
- 查询 8 条自建 FAQ：发货、运费、退换、台灯、水杯、托盘、订单变更、人工服务。
- 点击回答下方的“依据”查看对应条款，以及它可识别的问法。
- 对未匹配的问题查看人工联系流程，选择问题类型并生成**未发送**的请求预览。
- 重置对话，清除当前页面中的问答与请求预览。

可尝试“多久发货”“满多少包邮”“台灯怎么调光”“水杯能放洗碗机吗”，以及不在条款里的“有礼品刻字服务吗”。

## 检索与数据范围

当前逻辑是可读的本地关键词检索：去除问题空白，统计命中的预设词，选择分数最高的条款并返回固定答案；没有命中时转到人工流程说明。它不进行语言模型推理，不承诺理解所有自然语言表达，也没有假装查询真实订单。

对话只放在当前页面内存中。没有网络请求、Cookie、localStorage、IndexedDB、分析脚本或消息发送；刷新或关闭后不会保留本轮对话。请使用虚构问题，不输入真实个人资料。

用户文本、回复与联系请求预览均通过 DOM `textContent` 写入，避免把输入当作 HTML 执行。交互包含可见键盘焦点、输入标签、Enter 提交、Esc 关闭与原生对话框。

## 与原项目经历的区别

此示例用于直观体验网店前台的问答交互，**不是原公司项目源码，也不是原客服系统的界面或已上线服务**。原网站客服经历包括第三方客服平台实施、知识库接入、工作流配置、Shopify 后台接入及聊天窗口优化。另有独立的[邮件审核与案件协作案例](../cases/email-case-workflow.md)，两项分别介绍；这里没有复制任何原项目的实现、配置或资料。

后续可以按明确需求接入真实商品与政策知识库，增加服务端检索、语言模型回答、订单授权查询、人工工单及权限管理。真实平台与模型接入需要另行设计和实施，当前示例没有完成这些连接。

## 文件与技术

`customer-assistant.html`：单文件 HTML / CSS / JavaScript；原生 SVG 商品示意；零外部依赖。店铺陈列、知识条款、检索函数和界面事件均在文件内，可直接阅读和修改。

这是独立可运行的交互演示，不包含支付、购买或实际发信功能。
